# Licensing and citation

## Licensing

- **Data:** CDLA-Permissive-2.0. If you share the data, include the licence text with it.
  Attribution is not required, but please cite the corpus.
- **Code, tooling and the JSON schema:** Apache-2.0.
- **Documentation and dataset cards:** CC BY 4.0. Credit is required when you reuse them.

See [LICENSING.md](../LICENSING.md) for details and how to credit the documentation.

## Citation

Cite the corpus using `CITATION.cff` at the repository root, or:

> Okwu (2026). African Language Parallel Corpus (Version X.Y.Z).
> https://huggingface.co/datasets/Okwu/african-language-parallel-corpus

Replace X.Y.Z with the release you used. The current version is in `CITATION.cff` and the
latest entry in `CHANGELOG.md`.
